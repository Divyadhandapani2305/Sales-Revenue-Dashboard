# Global SuperStore Sales Insights

## 📌 Project Overview
This project is an interactive **Sales & Revenue Analysis Dashboard** built using Power BI for the **Thiranex** task. It analyzes global sales, profit, and product performance to help businesses make data-driven decisions.

## 🛠️ Tech Stack
* **Tool:** Power BI
* **Dataset:** SuperStoreOrder.csv 

## 📊 Key Highlights from Dashboard
* **Total Sales:** 12.64M
* **Total Profit:** 1.47M
* **Total Quantity Sold:** 178K
* **Top Product Categories:** Technology (4.74M) & Furniture (4.11M)
* **Top Sub-Categories:** Phones, Copiers, and Chairs
